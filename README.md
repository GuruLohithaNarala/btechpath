# BTechPath - Engineering Career & Learning Platform

**BTechPath** is a career-guidance and learning platform specifically designed for Indian B.Tech engineering students.

> *"Your 4-Year Engineering Journey, Simplified. Know what to learn. Know when to learn it."*

---

## 🚀 Key Features

- **Personalized Roadmap Generator**: 5-step interactive wizard tailored to student's Engineering Branch, Year, Target Career Goal, Skill Level, and Daily Study Hours.
- **Visual Flowchart Roadmaps**: Step-by-step career path visuals with statuses (Not Started, In Progress, Completed), resources, practice tasks, and quizzes.
- **4-Year Engineering Journey**: Structured breakdown from 1st Year (Fundamentals) to 4th Year (Placement & System Design).
- **8 Dedicated Career Tracks**: Full Stack, Data Analyst, AI/ML, Cloud/DevOps, Cybersecurity, Python Developer, Software Developer, Software Testing.
- **Interactive Learning Hub**: Categorized lessons with *"Explain Simply"* breakdowns (Analogies, Visual Diagrams, Code Examples, Memory Tips).
- **Quiz Engine & Progress Persistence**: Instant quiz scoring, attempt logging in MongoDB, and XP rewards.
- **Daily Recommendation Engine**: Dynamic daily action plans tailored to student profiles and study hours.
- **Comprehensive Project Hub**: Deep-dive project guides with DB designs, step-by-step instructions, GitHub checklists, and resume descriptions.
- **Placement Prep Portal**: Practice modules for DSA (Arrays to Graphs), Core CS (OS, DBMS, CN, OOP), Aptitude (Quant, Verbal, Logical), and Interview Q&As.
- **ATS Resume Builder & Analyzer**: Dynamic template editor with ATS scoring checks, keyword suggestions, and PDF export.
- **Tech Pulse**: Industry trend tracker with hiring demand indicators and recommended learning paths.
- **AI Mentor**: Interactive chat assistant offering instant study advice, tech choice guidance, and concept explanations.
- **Gamification**: XP points, daily streaks, badges (Python Beginner, SQL Explorer, DSA Starter, Project Builder, Quiz Master, Interview Ready).
- **Admin Analytics Dashboard**: System overview with Recharts analytics charts, student management, and content management.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite, Tailwind CSS, React Router v6, Lucide React Icons, Recharts
- **Backend**: Python 3.11+, Flask, Flask-CORS, PyMongo, PyJWT, Werkzeug
- **Database**: MongoDB
- **Security**: JWT Authentication, Bcrypt Password Hashing, CORS handling, Environment variables

## 💻 Getting Started

### Prerequisites
- Node.js (v18+) & npm
- Python (v3.10+)
- MongoDB (running locally or via MongoDB Atlas URI)

### Backend Setup
```bash
cd backend
python -m venv venv
# On Windows:
venv\Scripts\activate
# Install dependencies:
pip install -r requirements.txt
# Seed database with initial data:
python seed.py
# Run Flask server:
python app.py
```
Backend runs on `http://localhost:5000`

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on `http://localhost:5173`

## Deploying a Live Version

This repository is configured for a Vercel frontend and a Render API. Push the repository to GitHub, then:

1. In MongoDB Atlas, create a database user and database, allow connections from your Render service, and copy the application connection string. Replace its password placeholder with the database user's password.
2. In Render, choose **New + > Blueprint** and select this repository. Render reads `render.yaml` and creates the API service. Set `MONGO_URI` to the Atlas connection string. `JWT_SECRET` is generated by the blueprint.
3. Wait for the Render service to deploy, then verify `https://<render-service>.onrender.com/api/health` returns a healthy status.
4. In Vercel, import this same repository and set the project root directory to `frontend`. Set the environment variable `VITE_API_BASE_URL` to `https://<render-service>.onrender.com/api`, then deploy.
5. Open the Vercel URL to use the live site. After changing environment variables, redeploy the affected service.

Keep database credentials and other secrets in the hosting providers' environment-variable settings; do not commit them to the repository. The React app uses `VITE_API_BASE_URL` at build time, and `frontend/vercel.json` routes client-side page URLs back to the app.
